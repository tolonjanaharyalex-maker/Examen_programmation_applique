MATHLAB
=======

VERSION FINALE - CORRECTION COURBES

Correction principale:
- Le nom affiché dans la liste des fonctions est maintenant utilisé directement
  pour le calcul et le tracé.
- Le changement de fonction actualise immédiatement la formule et les champs.
- Les paramètres affichés correspondent à la fonction sélectionnée.
- Le graphique est recalculé et rafraîchi à chaque clic sur CALCULER ET TRACER.
- Exemple: en choisissant Exponentielle, l'écran affiche f(x)=a × b^x
  et la courbe devient exponentielle au lieu de rester affine.

Fonctions:
Affine, Linéaire, Polynôme, Puissance, Exponentielle, Logarithme.

Installation:
pip install -r requirements.txt

Lancement:
python main.py
